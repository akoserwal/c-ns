### Practical Backend + Platform + IAM Course (5 weeks)

This folder contains a **session-based, code-first** course optimized for a mentee converging on **Backend / Platform / IAM-adjacent Engineering**.

**North Star**: *“I can design, build, secure, deploy, and explain a real service.”*

#### How to use this course
- **Cadence (suggested)**: 3 sessions/week (90–120 min) + 1 self-paced lab (2–4 hrs)
- **Deliverables**: every week ends with a runnable artifact and a short written explanation
- **Rule**: if something breaks, slow down and answer: **what layer am I in?** (HTTP / validation / domain / persistence / infra)

#### Contents
- `week-01/` → `week-05/`: session plans + labs
- `code/`: runnable examples (Python/FastAPI/SQLAlchemy/Docker)
- `templates/`: reusable templates for sessions and mentee logs

#### Weekly map
- **Week 1**: HTTP + FastAPI fundamentals, dependency injection, boundaries
- **Week 2**: SQL-first relational modeling, joins, then SQLAlchemy mental model + integration
- **Week 3**: software design via refactoring (services, repos, SRP/DIP, minimal tests)
- **Week 4**: authn/authz, JWT mental models, Keycloak basics, role-based access patterns
- **Week 5**: Docker + Compose, deployment thinking, Kubernetes concepts, AWS primitives (selective depth)
